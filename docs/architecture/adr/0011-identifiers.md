# ADR-0011: UUIDv7 internal IDs + 8-character question codes
- Status: Proposed · Date: 2026-10-18
## Decision
- Internal IDs: **UUIDv7** (time-ordered, index-friendly), generated by the application.
- Question code: 8 characters, globally unique, permanent, never reused, random (cryptographic RNG), unique index + retry on collision.
- Alphabet: **Crockford Base32** (`0-9` and `A-Z` without `I L O U`). Input is case-insensitive and maps `O→0`, `I/L→1`. This avoids misreading codes on paper; 32^8 ≈ 1.1 trillion codes. (Refines spec-v1 P-04, which allowed all of A–Z/0–9.)
## Consequences
+ Codes are easy to read aloud/print; no semantic meaning leaks. − Codes are not sequential (by design).
