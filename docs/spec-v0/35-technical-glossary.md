# 35. Technical Glossary

**Master Question:** Stable conceptual identity shared by original and derived question variants.

**Variant:** Distinct usable question derived from the same Master.

**Question Version:** Immutable revision snapshot of a Variant/language content state.

**Source:** Origin/reference from which a question or content was obtained.

**Ingestion Batch:** A processing unit containing one or more uploaded source files.

**Ingestion Item:** One extracted question candidate in staging.

**Ingestion QC:** Review of extraction fidelity against source.

**Content QC:** Expert validation of question correctness and publication quality.

**AI Action:** A business-level AI capability such as `TAG_QUESTION` or `MODIFY_QUESTION`.

**AI Model:** Logical model family.

**AI Model Version:** Immutable provider model identifier/revision used for provenance.

**AI Job:** One execution of an AI Action.

**Prompt Version:** Immutable version of the prompt/schema configuration used for an AI job.

**Taxonomy:** Hierarchical classification such as Subject → Chapter → Topic → Concept → Sub-concept.

**Published:** Immutable version exposed as production-ready content.

**Test Version:** Immutable snapshot of a test configuration/questions at publication time.
